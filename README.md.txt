# Smart Data Insights Dashboard

## Overview
An executive-level business intelligence dashboard built using SQL and Power BI to analyze sales performance, profitability, customer behavior, and regional trends using 5000+ records.

---

## Tools & Technologies
- SQL
- Power BI
- DAX
- Data Visualization
- Business Intelligence

---

## Key KPIs
- Total Revenue
- Total Profit
- Revenue Growth %
- Average Order Value
- Regional Performance

---

## Key Insights
- Clothing category generated highest profit
- West region contributed highest revenue
- UPI and Net Banking dominated customer payments
- Revenue trends showed seasonal spikes
